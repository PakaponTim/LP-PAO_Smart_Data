OPEN DATA API FOR PARTNER AGENCIES

🔌 API เชื่อมโยงข้อมูลสำหรับหน่วยงานที่เกี่ยวข้อง (มาตรฐานความปลอดภัยสูง)

หน่วยงานเครือข่ายใน จ.ลำปาง (ปภ.จังหวัด, อำเภอ, เทศบาล/อบต.) สามารถดึงข้อมูลไปใช้ต่อยอดได้อย่างปลอดภัย

📄 OpenAPI 3.0 Spec 🔑 ออก / จัดการ API Key หน่วยงาน
🛡️ Zero-PII Redaction

ตัด/ปิดบังเบอร์โทร, เลขบัตรประชาชน 13 หลัก, อีเมล, LINE ID และไม่ส่งออกประวัติแชทภายใน

🔑 SHA-256 Agency Key

เส้นทาง /api/public/agency/* บังคับใช้ X-API-Key (เก็บเฉพาะ SHA-256 Hash ใน Server)

🚦 Sliding Rate Limiting

ป้องกันการยิงถล่มระบบด้วย Rate Limit ต่อ IP / Key (HTTP 429 + X-RateLimit-*)

🔒 Read-Only & Audit Log

อนุญาตเฉพาะคำสั่งอ่าน GET เท่านั้น และบันทึกประวัติการดึงของแต่ละหน่วยงานลง Log

🛠️ กดเพื่อเปิด/ปิด เครื่องมือทดสอบยิง API สด (สำหรับนักพัฒนาและเจ้าหน้าที่เทคนิค) คลิกเพื่อกางออก ▾
