OPEN DATA API FOR PARTNER AGENCIES

ข้อมูลเปิดและ API เชื่อมโยงข้อมูลสำหรับหน่วยงาน

OpenAPI 3.0 Spec จัดการ API Key
Zero-PII Redaction

คัดกรองเบอร์โทร เลขบัตรประชาชน อีเมล และไม่ส่งออกประวัติแชทภายใน

SHA-256 Agency Key

เส้นทาง /api/public/agency/* ใช้ X-API-Key แบบ Hash

Sliding Rate Limiting

ควบคุมอัตราการเรียกใช้งานต่อ IP / Key พร้อม Header แจ้งโควตา

Read-Only & Audit Log

อนุญาตเฉพาะคำสั่งอ่าน GET พร้อมบันทึก Log ทุกครั้ง

รายการ Public & Inter-Agency Endpoints
GET /api/public/overview

GET /api/public/traffy?limit=5

GET /api/public/traffy/cases/{id}/timeline
ประวัติการดำเนินงานจริงรายเคส (Zero-PII Timeline)
