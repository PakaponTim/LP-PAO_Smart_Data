# การดึงข้อมูลเรื่องร้องเรียน Traffy

## สาเหตุที่พบวันที่ 25 กันยายน 2569

- หน้า Chrome แสดงเรื่องร้องเรียน 20 เรื่อง แต่แผง Traffy Extension แจ้งว่าไม่ได้จับคู่กับ Water System จึงไม่มีการเชื่อมต่อ Socket และไม่สามารถส่งข้อมูลได้
- Puppeteer เปิดเบราว์เซอร์ใหม่ซึ่งไม่มีสถานะเข้าสู่ระบบของ Chrome และถูกส่งจาก `/recent-post` ไป `/login` จึงไม่สามารถอ่านการ์ดเรื่องร้องเรียนได้
- การทำงานเดิมซ่อนข้อผิดพลาดของตัวเก็บข้อมูล ทำให้ตัวตั้งเวลารอต่อและแจ้ง timeout ซ้ำหลังงานล้มเหลวแล้ว

## การใช้งาน

1. เข้าสู่ระบบ Traffy ใน Chrome แล้วเปิด `https://citydata.traffy.in.th/recent-post` โดยเลือกหน่วยงานและตัวกรองที่ต้องการ
2. จับคู่ **Traffy Fondue Scraper for Lampang** ในหน้าตัวเลือกส่วนขยายกับ Water System โดยใช้บัญชีผู้ดูแลระบบ ส่วนขยายนี้ต้องจับคู่แยกจากส่วนขยาย ThaiWater
3. ตรวจแผงส่วนขยายว่าขึ้น **เชื่อมต่อ backend สำเร็จ**
4. คงแท็บและ Chrome ไว้ระหว่างรอบอัตโนมัติ

การเปิดหน้าเว็บเพียงอย่างเดียวไม่ใช่หลักฐานว่าจับคู่กับ Water System แล้ว ส่วนขยายเก็บกุญแจอุปกรณ์โดยไม่เก็บรหัสผ่านผู้ดูแลระบบ

## พฤติกรรมหลังแก้ไข

- ส่งคำสั่งไปยัง Traffy Extension ที่เชื่อมต่อเพียงหนึ่งแท็บ และไม่เริ่มงานร้องเรียนซ้อนกัน
- ยืนยันงานเสร็จจากผล commit ของฐานข้อมูล สำหรับส่วนขยายที่รองรับจะจับคู่ด้วยรหัสงาน สำหรับรุ่นเดิมจะยอมรับเฉพาะการบันทึกจากอุปกรณ์ที่ server เลือกส่งคำสั่งให้
- ยกเลิกตัวจับเวลาเมื่อบันทึกสำเร็จ จึงไม่เปิด fallback ตามมาหลังจบงาน
- เมื่อพบหน้า login ใน Puppeteer จะคืน `TRAFFY_AUTH_REQUIRED` ทันที ไม่ retry กรณีนี้ และไม่รอ timeout เพิ่มในตัวตั้งเวลา
- ไฟล์ส่วนขยายในโปรเจกต์เพิ่มข้อความเตือนการจับคู่ ปุ่มเปิดหน้าตัวเลือก และใช้รหัส batch เดิมระหว่าง retry

## ตรวจสอบ

```powershell
$env:WATER_DB_TEST = '1'
node --test tests/*.test.js
node scripts/check-syntax.mjs
node scripts/verify-traffy-storage.mjs
```

ทดสอบช่องทาง Puppeteer แบบอ่านอย่างเดียว (ต้องออกอินเทอร์เน็ตได้):

```powershell
node scripts/verify-traffy-fallback.mjs
```

คำสั่งนี้คาดหวัง `TRAFFY_AUTH_REQUIRED` จากเบราว์เซอร์ใหม่ และตรวจว่า error ถูกส่งกลับทันทีโดยไม่เขียนฐานข้อมูล

Log ของ server ที่เริ่มหลังแก้ไข: `runtime/server-20260925-fixed.stdout.log` และ `runtime/server-20260925-fixed.stderr.log`
