๑
บทนำ — ปัญหาและข้อจำกัดก่อนมีระบบ
ที่มาและเหตุผลในการพัฒนาระบบ

กองยุทธศาสตร์และงบประมาณ องค์การบริหารส่วนจังหวัดลำปาง มีหน้าที่ติดตามสถานการณ์สิ่งแวดล้อมและภัยพิบัติในพื้นที่จังหวัดลำปาง เพื่อสนับสนุนการวางแผนยุทธศาสตร์และการตัดสินใจเชิงนโยบายของผู้บริหาร ก่อนที่จะมีการพัฒนาระบบนี้ขึ้น การทำงานในส่วนดังกล่าวยังคงพึ่งพากระบวนการทำงานด้วยมือ ซึ่งมีข้อจำกัดหลายประการ

  • ข้อมูลกระจัดกระจาย — ข้อมูลปริมาณน้ำฝน ระดับน้ำ คุณภาพอากาศ PM 2.5 และเรื่องร้องเรียนต่าง ๆ ถูกจัดเก็บแยกกันในหลายแหล่ง ทำให้ยากต่อการนำมาวิเคราะห์ร่วมกัน
  • เสียเวลาในการรวบรวมข้อมูล — เจ้าหน้าที่ต้องเปิดเว็บไซต์หลายแห่งด้วยตนเอง จดบันทึก และพิมพ์ข้อมูลลงตารางซ้ำ ๆ ทุกวัน ซึ่งใช้เวลามากและอาจเกิดข้อผิดพลาดได้
  • ข้อมูลตกหล่นได้ง่าย — หากเจ้าหน้าที่ลาหยุดหรือติดภารกิจอื่น ข้อมูลของวันนั้นจะขาดหายโดยไม่มีระบบสำรอง
  • ไม่มีระบบแจ้งเตือนอัตโนมัติ — เมื่อค่า PM 2.5 หรือระดับน้ำเกินค่าวิกฤต ไม่มีระบบแจ้งเตือนผู้เกี่ยวข้องได้ทันที ต้องรอให้เจ้าหน้าที่ตรวจสอบเองก่อน
  • การจัดทำรายงานล่าช้า — รายงานสรุปสถานการณ์ต้องรวบรวมและพิมพ์ข้อมูลด้วยมือ ใช้เวลาหลายชั่วโมงต่อฉบับ ไม่ทันต่อความต้องการ

ผลกระทบ: ข้อมูลที่ได้ไม่ทันต่อสถานการณ์จริง ทำให้การตัดสินใจเชิงนโยบายล่าช้า และเสี่ยงต่อการมองข้ามสัญญาณเตือนภัยล่วงหน้า ซึ่งส่งผลโดยตรงต่อประสิทธิภาพการบริหารงานของกอง

อบจ.ลำปาง | กองยุทธศาสตร์และงบประมาณ หน้า ๒
๒
นวัตกรรมแก้ปัญหา — ระบบที่พัฒนาขึ้น
แนวทางและจุดเด่นของระบบบูรณาการข้อมูล

เพื่อแก้ไขปัญหาข้างต้น ได้ออกแบบและพัฒนา "ระบบบูรณาการข้อมูลสิ่งแวดล้อมและภัยพิบัติ" ขึ้นด้วยตนเอง ระบบนี้ทำหน้าที่เสมือนเจ้าหน้าที่ดิจิทัลที่ทำงานตลอด ๒๔ ชั่วโมงโดยไม่ต้องมีคนควบคุมตลอดเวลา มีจุดเด่นสำคัญ ดังนี้

๑
ทำงานอัตโนมัติ ๑๐๐%
ระบบดึงข้อมูลจากแหล่งภายนอกอัตโนมัติทุก ๓๐ นาที ตลอด ๒๔ ชั่วโมง โดยไม่ต้องให้เจ้าหน้าที่มาดำเนินการด้วยตัวเอง ทำให้ข้อมูลพร้อมใช้งานได้ทุกเมื่อ แม้จะเป็นวันหยุดหรือนอกเวลาราชการ
๒
สำรองข้อมูล ๒ ทางพร้อมกัน
ทุกข้อมูลที่เก็บได้จะถูกบันทึกพร้อมกันทั้งในฐานข้อมูล MySQL และไฟล์ Excel อัตโนมัติ เพื่อป้องกันข้อมูลสูญหาย แม้ระบบใดระบบหนึ่งมีปัญหาก็ยังมีอีกระบบรองรับอยู่เสมอ
๓
แจ้งเตือนภัยวิกฤตอัตโนมัติ
เมื่อพบสถานการณ์วิกฤต เช่น ค่า PM 2.5 เกินมาตรฐาน หรือระดับน้ำสูงผิดปกติ ระบบส่งอีเมลแจ้งเตือนผู้เกี่ยวข้องทันที พร้อมมีระบบ Smart Cooldown ป้องกันการแจ้งเตือนซ้ำซ้อนภายใน ๒ ชั่วโมง
๔
แดชบอร์ดดูสถานการณ์แบบ Real-time
มีหน้าเว็บแดชบอร์ดแสดงข้อมูลล่าสุดพร้อมแถบสีระดับความรุนแรง ๔ ระดับ ทำให้เจ้าหน้าที่ทราบสถานการณ์ได้ทันทีโดยไม่ต้องเปิดเว็บไซต์หลายแห่ง

ผลลัพธ์โดยรวม: เจ้าหน้าที่ไม่ต้องเสียเวลากับงานรวบรวมข้อมูลซ้ำซ้อนอีกต่อไป สามารถมุ่งความสนใจไปยังการวิเคราะห์เชิงลึกและการสนับสนุนการตัดสินใจเชิงนโยบายได้มากขึ้น

๓
ขอบเขตข้อมูล — ๔ มิติที่บูรณาการไว้ในระบบ
ข้อมูลที่ระบบติดตามและจัดเก็บอย่างต่อเนื่องทุกวัน

ระบบได้รวบรวมข้อมูลจากหลายแหล่งเข้ามาจัดเก็บในที่เดียว ครอบคลุม ๔ มิติข้อมูลสำคัญที่เกี่ยวข้องกับสิ่งแวดล้อมและภัยพิบัติในพื้นที่จังหวัดลำปาง

💧 น้ำและปริมาณน้ำฝน

ติดตามปริมาณน้ำฝนสะสม ระดับน้ำในแม่น้ำและลำน้ำสำคัญ รวมถึงสถานีวัดน้ำในพื้นที่เสี่ยงอุทกภัยของจังหวัดลำปาง ข้อมูลอัปเดตทุก ๓๐ นาที

🏞️ ภัยแล้งและอ่างเก็บน้ำ

ติดตามปริมาณน้ำในอ่างเก็บน้ำสำคัญ ความจุของแหล่งน้ำ เพื่อใช้ประเมินแนวโน้มสถานการณ์ภัยแล้งล่วงหน้า ช่วยสนับสนุนการวางแผนบริหารน้ำ

🌫️ คุณภาพอากาศ PM 2.5

ติดตามค่าฝุ่นละอองขนาดเล็ก PM 2.5 จากสถานีตรวจวัดในจังหวัดลำปาง พร้อมระบบแจ้งเตือนอัตโนมัติเมื่อค่าเกินมาตรฐานที่กำหนด

📋 เรื่องร้องเรียน Traffy Fondue

ดึงข้อมูลเรื่องร้องเรียนด้านสิ่งแวดล้อมจากระบบ Traffy Fondue กรองเฉพาะเรื่องที่เกี่ยวข้องกับ อบจ.ลำปาง เพื่อติดตามสถานการณ์และการแก้ไข

คุณค่าของการบูรณาการข้อมูล: การที่ข้อมูลทั้ง ๔ มิติอยู่ในที่เดียวและเชื่อมถึงกันได้ ทำให้สามารถวิเคราะห์ความสัมพันธ์ระหว่างสภาพอากาศ ระดับน้ำ คุณภาพอากาศ และปัญหาที่ประชาชนร้องเรียนได้อย่างรอบด้าน อันนำไปสู่การตัดสินใจเชิงนโยบายที่มีประสิทธิภาพยิ่งขึ้น

เทคโนโลยีและวิธีการดึงข้อมูลจากแหล่งภายนอก

ระบบใช้เทคโนโลยีดึงข้อมูลจากเว็บไซต์ภายนอกแบบอัตโนมัติ โดยมีกลไกทำงาน ๒ ชั้น เพื่อให้มั่นใจว่าข้อมูลจะถูกเก็บได้ แม้เว็บไซต์ต้นทางมีปัญหาชั่วคราว

①
วิธีหลัก — Chrome Extension Controller
ใช้ระบบควบคุมเบราว์เซอร์ Chrome เพื่อเปิดหน้าเว็บและอ่านข้อมูลอัตโนมัติ เหมาะสำหรับเว็บไซต์ที่ใช้ JavaScript หรือต้องการการโต้ตอบเพื่อแสดงข้อมูล
②
วิธีสำรอง — Puppeteer Fallback
หากวิธีหลักดำเนินการไม่ได้ ระบบจะสลับไปใช้ Puppeteer ซึ่งเป็นเครื่องมือเบราว์เซอร์อัตโนมัติอีกประเภทหนึ่ง ทำให้ข้อมูลยังถูกเก็บได้อย่างต่อเนื่อง

ความมั่นคงของข้อมูล — ระบบสำรองคู่ขนาน

🗄️ ฐานข้อมูล MySQL

เหมาะสำหรับการสืบค้นย้อนหลัง การวิเคราะห์เชิงสถิติ และการนำไปแสดงบนแดชบอร์ด ข้อมูลไม่สูญหายแม้ระบบเกิดปัญหาชั่วคราว

📊 ไฟล์ Excel อัตโนมัติ

ระบบสร้างและอัปเดตไฟล์ Excel ให้อัตโนมัติ ทำให้เจ้าหน้าที่นำข้อมูลไปใช้ต่อได้ทันที โดยไม่ต้องมีความรู้ด้านฐานข้อมูล

กลไกซ่อมแซมตัวเอง (Auto-Retry): หากการบันทึกข้อมูลไม่สำเร็จในครั้งแรก ระบบจะพยายามบันทึกซ้ำอัตโนมัติ ส่งผลให้ข้อมูลถูกบันทึกได้ครบถ้วนในอัตราสูงมาก แม้ในสภาวะที่ไฟล์ถูกเปิดค้างหรือเครือข่ายมีปัญหา

ระบบแจ้งเตือนสถานการณ์วิกฤต
การแจ้งเตือนอัตโนมัติเมื่อพบสัญญาณอันตราย

ระบบมีการกำหนดค่าเกณฑ์วิกฤตสำหรับข้อมูลแต่ละประเภท เมื่อค่าใดค่าหนึ่งเกินเกณฑ์ที่กำหนด ระบบจะดำเนินการแจ้งเตือนผู้เกี่ยวข้องโดยอัตโนมัติทันที

  • ส่งอีเมลแจ้งเตือนทันที — ระบุรายละเอียดค่าที่วัดได้ สถานีวัด วันเวลา และระดับความรุนแรง ให้ผู้รับสามารถดำเนินการได้ทันที
  • ระบบ Smart Cooldown ๒ ชั่วโมง — หลังจากส่งการแจ้งเตือนครั้งหนึ่งแล้ว ระบบจะรอ ๒ ชั่วโมงก่อนส่งซ้ำในกรณีสถานการณ์ยังคงอยู่ เพื่อป้องกันการแจ้งเตือนมากเกินไปจนก่อให้เกิดความสับสน
  • รองรับหลายประเภทสถานการณ์ — ค่า PM 2.5 เกินมาตรฐาน ระดับน้ำสูงวิกฤต ปริมาณน้ำในอ่างเก็บน้ำต่ำกว่าเกณฑ์ รวมถึงแจ้งเตือนเมื่อระบบเกิดข้อขัดข้อง

นอกจากระบบแจ้งเตือน ยังมีหน้าแดชบอร์ดเว็บที่แสดงข้อมูลสดแบบ Real-time ซึ่งเจ้าหน้าที่สามารถเข้าถึงได้จากคอมพิวเตอร์หรือโทรศัพท์มือถือตลอดเวลา

🟢 แถบสีแสดงระดับความรุนแรง

  • รายงานรายวัน — สรุปสถานการณ์ประจำวัน พร้อมค่าสูงสุด ต่ำสุด และค่าเฉลี่ยของข้อมูลแต่ละประเภทในรอบ ๒๔ ชั่วโมงที่ผ่านมา
  • รายงานรายสัปดาห์ — เปรียบเทียบแนวโน้มสถานการณ์ในรอบ ๗ วัน พร้อมตารางสรุปและข้อสังเกต
  • รายงานรายเดือน — สรุปภาพรวมสถานการณ์สิ่งแวดล้อมประจำเดือน เหมาะสำหรับรายงานต่อผู้บริหารและเผยแพร่ต่อสาธารณะ
